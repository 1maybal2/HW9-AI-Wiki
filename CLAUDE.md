# Project: My AI Learning Wiki

## 1. Project Purpose (專案目的)
This project is a personal knowledge base documenting my journey learning Generative AI. It serves as a digital notebook where I can easily add new articles, summaries, and reflections.

## 2. Overall Style (整體風格)
- **Theme:** Minimalist, clean, and readable.
- **Colors:** Pastel accents (soft pink, light blue, mint green) with a white background.
- **Typography:** Sans-serif fonts (like Arial or Helvetica) for easy reading.
- **Layout:** Two-column layout (Sidebar for navigation on the left, Main content on the right).

## 3. Page Structure (頁面結構)
Every page should follow this structure:
- **Header:** Title of the Wiki and a brief description.
- **Sidebar:** A list of links to different articles.
- **Main Content:** The actual article text, formatted with Markdown-style headings.

## 4. Rules for Adding New Content (新增內容的規則)
When I ask AI to add a new article, it MUST follow these rules:
1. **File Naming:** New HTML files must be named `[topic-name].html` (e.g., `rag.html`).
2. **HTML Structure:** The new page must copy the exact layout (Header, Sidebar, Main Content) of `index.html`.
3. **Linking:** The new article must be added as a new `<li><a>` tag in the Sidebar of ALL existing pages.
4. **Content Style:** Articles must be written in Traditional Chinese (or English) with clear headings and bullet points.

## 5. AI Instructions (AI 修改規則)
- Always ask for confirmation before deleting any existing content.
- Keep the HTML code clean and indented.
